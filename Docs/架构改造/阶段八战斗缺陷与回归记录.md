# 阶段八战斗缺陷与回归记录

两项修复均已通过正式主场景运行模式回归。改动涉及敌人战斗模块、感知模块和主控制器的更新入口。测试使用正式敌人模板，在内存中布置平地和目标位置；退出运行后主场景未被修改。

## 普通站立攻击挥空后继续命中

普通敌人的三段站立攻击片段都在动作进度约百分之五十五发送命中标记，约百分之九十五发送完成标记。战斗模块同时有逐帧兜底，用于动画标记未到的情况。旧实现只在玩家受伤、格挡或友军受击后记下命中编号。挥空时编号保持未命中，兜底在收招过程中反复检查距离。

现在同一次普通站立挥击只有一次取样机会。动画标记和兜底共用它，先到的一方在检查距离、角度、视线、格挡和友军之前收窗。实际命中记录继续独立保存。先收到完成通知也会收窗，下一次攻击起手时重新开放。电锯各段仍使用各自的命中编号，爬行仍沿用原判定。[战斗模块](../../Assets/Scripts/Enemy/敌人战斗模块.cs)

| 同一正式预制件、相同位置与进度 | 修复前 | 仅修复挥空后 |
|---|---:|---:|
| 玩家在进度百分之五十六时位于八米外，百分之七十八时回到零点八米，随后收到重复标记 | 补扣十点 | 零点 |
| 攻击完成通知后收到迟到命中标记 | 扣十点 | 零点 |
| 下一次攻击在范围内命中，再重复发送标记 | 总计十点 | 总计十点 |

## 战斗中硬直积累没有恢复

原衰减公式在感知更新的最后。已进入战斗的敌人刷新目标记忆后提前返回，因此追击和攻击时，即使已经过了恢复延迟，积累值也不会下降。现在由角色在有效更新帧独立调用战斗模块推进恢复。延迟仍从最近一次受击起算，沿用原来的缩放游戏时间、每秒衰减值和零下限。[角色更新顺序](../../Assets/Scripts/Enemy/VillagerController.cs) · [感知模块](../../Assets/Scripts/Enemy/敌人感知模块.cs)

回归使用普通模板的原参数，恢复延迟一点五秒、每秒八点、硬直门槛二十点。修复前和只改挥空后，超过延迟的追击帧和攻击帧均停在四点。两项修复后，每次实际减少量都与该帧游戏时间乘以八相符。另在自然更新中等待原延迟，验证积累降至零；暂停时数值保持，两次快速非致命命中累计跨过门槛仍会触发硬直。

## 人工体验

实机可重点体验两个场景。普通村民挥击时后撤，看到手臂收回再上前，观察受伤反馈是否与画面一致。随后用相同武器分别连续、隔开射击同一类敌人，观察硬直反馈是否能区分两种节奏。自动回归验证了判定、扣血和时序，以上动作观感仍待人工签收。本轮未进行新的性能对照采样。
